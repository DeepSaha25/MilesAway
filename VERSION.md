## AI Change Rules

When AI makes a code, configuration, or documentation change in this repository, it must update `CHANGELOG.md` in the same work session.

Each changelog entry should include:

- version and date
- summary of the change
- files changed
- verification performed
- follow-up notes or risks

## Versioning Guide

- Patch version: bug fixes, small documentation changes, safe configuration updates.
- Minor version: new features, new workflows, meaningful app or backend behavior changes.
- Major version: breaking API changes, major architecture changes, incompatible release changes.
